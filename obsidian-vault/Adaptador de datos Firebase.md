# Adaptador de datos Firebase

Funciones de html/js/app.js para escuchar Realtime Database, leer datos mediante REST, escribir eventos/tokens y recuperar estado del gateway. La capa permite fallback REST cuando corresponde.

Usa [[Configuración Firebase web]], está bajo [[Sesión y autenticación]] y sincroniza [[Agenda y calendario]], [[Notificaciones de agenda y sistema]], [[Controles del hogar]] y [[TV y medios]]. Reglas asociadas: [[Reglas de Realtime Database]].
